## Text

### Headings

`CommonMark` · Mit `#` am Zielanfang entsteht eine Überschrift, `#` bis `######` ergeben sechs Ebenen. 

```markdown
#### Eine Überschrift mit der Ebene 4 
```

#### Eine Überschrift der Ebene 4 

### Paragraphs and line breaks 

`CommonMark` · Eine Leerzeile startet einen neuen Absatz. Ein `\`am Zeilenende erzwingt einen Zeilenumbruch im selben Absatz. 

```markdown
Erste Zeiele\
zweite Zeile im selben Absatz.

Ein neuer Absatz.
```

Erste Zeile\
zweite Zeile im selben Absatz. 

Ein neuer Absatz. 

### Italic, bold and both

`CommonMark` · Ein Sternchen macht Text kursiv, zwei machen ihn fett, drei beides. 

```markdown
~~durchgestrichten~~
```

~~durchgestrichten~~

### Inline Code 

`CommonMark`· Backticks markieren Code mitten im Satz. 

```markdown
Installiere es mit `pip install pandas`.
```

Installiere es mit `pip install pandas`

### Escaping a character 

`CommonMark` Ein `\` vor einem Sonderzeichen zeigt das Zeichen selbst an, statt es als Formatierung zu lesen. 

```markdown
\*kein kursiv\*
```
\*kein kursiv\*
